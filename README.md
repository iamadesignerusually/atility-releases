# Atility

Atility shows what fills your Mac and helps you clean up safely. Everything goes to the Trash or to iCloud and can be undone from the history. Atility never touches your Photos library.

This repository only hosts the finished downloads. Get the latest version under **Releases**.

## Install

1. Download `Atility.dmg` from the latest release and open it.
2. Drag Atility into Applications.
3. First launch on macOS 15 or later: open Atility once, then go to System Settings › Privacy & Security and click "Open Anyway".

Requires macOS 14 or later, Apple Silicon or Intel.
